The `octolens` CLI is published as the `octolens` package on npm and runs on Node.js `>=20`.

## Install

```bash
npm install -g octolens
octolens version
```

Or run it without installing:

```bash
npx octolens version
```

## Authenticate

Authenticate the CLI (browser handoff or API key) — every command that calls the Octolens API needs a credential first.

```bash
octolens login
octolens login --with-key
octolens login --with-key ak_live_xxx
```

Credentials are resolved per run: an API key in `OCTOLENS_API_KEY`, or a profile stored by `octolens login`. [The auth preflight](/cli/contract/auth-preflight) has the full rules, including what a run without a usable credential answers with.
