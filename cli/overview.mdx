## The contract

- [The --json contract](/cli/contract/json-output) — --json emits exactly one machine-readable JSON document on stdout with no decoration; progress and diagnostics go to stderr.

- [RESPONSE_LOST — the indeterminate write](/cli/contract/response-lost) — A state-changing request whose 2xx status line arrived but whose response body was lost answers RESPONSE_LOST (status 502, exit 10): the server accepted the write and the outcome…
