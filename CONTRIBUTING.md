# Contributing to the Octolens docs

Most of this site is hand-written MDX — edit it here and open a PR.

Two sections are **not** hand-written, and editing them here is wasted work:

## `cli/**` — generated, do not hand-edit

Every page under `cli/` is generated from the `octolens` CLI's own contract manifest in the
[octolens monorepo](https://github.com/octolens/octolens), not written here. A hand edit in this
repo survives only until the next sync, which overwrites the tree wholesale.

| | |
|---|---|
| Source of truth | `docs/cli/contract.json` in `octolens/octolens` (emitted by `pnpm cli:contract` from the CLI's command definitions) |
| Renderer | `pnpm cli:docs:site` in `octolens/octolens`, which writes `docs/cli/site/` |
| Guard | a CI drift gate in the monorepo fails the build if the committed tree doesn't match a fresh render |

### To change a CLI page

1. Change the CLI itself in `octolens/octolens` — the flag, the description, the exit codes. The
   manifest describes the binary, so the docs only move when the binary does.
2. Regenerate: `pnpm cli:contract && pnpm cli:docs:site`.
3. Merge that to the monorepo's `main`.
4. Re-sync into this repo:

   ```bash
   rsync -a --delete <octolens>/docs/cli/site/cli/ <docs>/cli/
   ```

   and, if the nav changed, replace the `"tab": "CLI"` entry in `docs.json` with the object in
   `<octolens>/docs/cli/site/docs.json` (its page paths are already docs-root-relative).

The pages published here are the **customer** edition of the manifest: internal-only flags and
hidden commands are excluded by the generator. Don't add them back by hand.

## `api/v2/**` — generated by Mintlify at build time

The API v2 reference is rendered by Mintlify from the live OpenAPI document at
`https://app.octolens.com/api/v2/openapi.json` (see the `openapi` key on the API v2 nav group).
There are no endpoint pages in this repo to edit — change the API's OpenAPI output instead.
