**Octolens MCP** lets AI assistants like Claude, ChatGPT, and Cursor access your Octolens workspace directly. Instead of switching between tabs and dashboards, just ask questions in natural language — your AI assistant browses mentions, filters by source or sentiment, runs analytics, and manages your monitoring setup on your behalf.

MCP (Model Context Protocol) is an open standard that connects AI tools to third-party services in a secure, consistent way.

<Note>
For shell scripts, CI pipelines, and bulk export, the [Octolens CLI](/cli/overview) is often the better surface — same data, stable exit codes, and a strict `--json` contract built for automation.
</Note>

- "Generate a share of voice graph using my BRAND, COMPETITOR 1, and COMPETITOR 2, with percentage share, mention volume, and sentiment breakdown."
- "Show me all Reddit mentions from the last week where sentiment is negative."
- "Add 'next.js deployment' as a new keyword and route buy-intent mentions to my #leads Slack channel."
- "Summarize the feature requests from the last 7 days."

## What your assistant can do

Your AI assistant gets the **full Octolens surface**: every action available in the app is available to it.

**Reads:** mentions, keywords, feeds, tags, keyword suggestions, keyword health, workspace and company profile, usage, and global filters, plus analytics, one-time searches and CSV exports.

**Writes:** create and manage keywords and feeds, including wiring up Slack, email, and webhook notification destinations.

## Authentication

Octolens uses **OAuth**, so there's no API key or token to paste. On first use, your AI client opens a browser tab, you sign in to Octolens and approve the connection, and you're ready. Your token never lives in a URL or config file.

#### Connection URL

```text
https://app.octolens.com/api/mcp/v2
```

Add this URL in your AI client and complete the OAuth sign-in. Step-by-step instructions for each tool are in the [Setup Guides](/mcp/v2/setup-guides).

<Note>
MCP is intended for interactive AI-client workflows. For scripts, backend jobs, or production integrations, use the [REST API](/api/v2/overview).
</Note>

## Security: mentions are untrusted content

Every mention Octolens delivers was written by an unknown third party somewhere on the internet. When your AI assistant reads mentions through this MCP server, that content is **data, not instructions** — a post could contain text deliberately crafted to steer an AI agent ("prompt injection").

Octolens scores mentions for relevance and sentiment, but does not remove or neutralize adversarial text.

Practical guidance:

- Be deliberate about combining Octolens with write-capable tools (email, code, payments, file access) in the same agent session. Prefer read-only sessions when browsing mentions.
- If your agent acts on mentions automatically, gate consequential actions behind a confirmation step.
- Tell your agent explicitly that mention text is quoted third-party content and never a source of instructions.

## Terms of Use

The Octolens MCP server is intended for use with MCP-compatible AI clients (such as ChatGPT, Claude, and Cursor) for interactive, AI-driven workflows.

**Not permitted:** Using the MCP endpoint via custom scripts, bridges, or standalone HTTP/JSON-RPC clients is unsupported and not permitted. The MCP server is not a general-purpose programmatic API.

**For programmatic access:** Use the Octolens API instead — see the [API documentation](/api/v2/overview).
