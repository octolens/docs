**`octolens onboard feeds`**

**Flags**

| Flag | Type | Required (headless) | Description |
|---|---|---|---|
| `--confirm` | `boolean` | no | Keep the feeds as they are now and go on to Slack |
| `--if-revision` | `string` | no | Refuse (exit 2, ONBOARDING_REVISION_CHANGED) unless the onboarding is still at this revision (the envelope's `revision`) |
| `--no-browser` | `boolean` | no | Never open a browser: print links instead |
| `--plain` | `boolean` | no | Append-only output: no colour, nothing redrawn (screen readers, logs) |
| `--remove` | `string` | no | Remove a feed by board number or id (repeatable; needs --yes) |
| `--rename` | `string` | no | Rename a feed: &lt;feed&gt;=&lt;name&gt;, where &lt;feed&gt; is its board number or id (repeatable) |
| `--wait` | `integer` | no | Seconds to wait while your feeds are still being made (--json default 45, max 600). A wait that runs out answers status "running" with a poll nextAction, exit 0. |
| `--yes` | `boolean` | no | Confirm --remove. On its own it never removes a feed. |
