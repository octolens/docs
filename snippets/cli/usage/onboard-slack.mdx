**`octolens onboard slack`**

**Flags**

| Flag | Type | Required (headless) | Description |
|---|---|---|---|
| `--email-only` | `string` | no | Keep a feed out of Slack, in the daily email only: its number or id (repeatable) |
| `--if-revision` | `string` | no | Refuse (exit 2, ONBOARDING_REVISION_CHANGED) unless the onboarding is still at this revision (the envelope's `revision`) |
| `--no-browser` | `boolean` | no | Never open a browser: print links instead |
| `--no-deliver` | `boolean` | no | Save the routes without sending the first mentions now |
| `--plain` | `boolean` | no | Append-only output: no in-place redraw, no animation (screen readers, logs) |
| `--route` | `string` | no | Send a feed to a Slack channel: &lt;feed&gt;=#&lt;channel&gt;, where &lt;feed&gt; is the feed's number or id (repeatable). Feeds you don't name keep the suggested channel. |
| `--skip` | `boolean` | no | Skip Slack. The daily email digest stays on; connect later with `octolens slack connect`. |
| `--wait` | `integer` | no | Seconds to wait for server work before answering (--json default 45, max 600; a TTY waits until done). A wait that runs out answers status "running" with a poll nextAction, exit 0. |
| `--yes` | `boolean` | no | Accept SAFE defaults without asking. Never removes a feed or writes MCP config on its own: those need their explicit flag too. |
