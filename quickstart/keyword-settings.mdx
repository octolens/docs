Keyword settings control what each keyword matches. Global settings add rules that apply to every keyword at once.

## Open keyword settings

On the **Keywords** page, click **Edit** on a keyword's row, or choose **Keyword settings** from the **···** menu. The settings open in a side sheet.

<Frame caption="Keyword settings for a single keyword.">
  <img src="/images/keyword-add-sheet.png" alt="Keyword Settings sheet showing Keyword, Platforms, Keyword context, Posts must ALSO include, Negative terms, Negative authors, Wildcard negative terms, and Matching criteria fields" />
</Frame>

For [common words](/quickstart/keywords#add-a-keyword), Octolens pre-fills context, negative terms, and "any of" terms. This sheet is where you review them.

## Keyword and tag

- **Keyword:** the term you track. Editing it only affects new mentions.
- **Tag:** Own Brand, Competitor, or Industry Term. The AI assigns it, and you can change it in the **Select tag** dropdown.

## Platforms

Every platform on your plan is on by default. Turn one off to stop collecting mentions from it for this keyword only. For example, keep an industry term on Reddit and Hacker News but drop it on X. See [Tracked Platforms](/learn/platforms/overview) for the list and refresh intervals.

The bottom of the dropdown lets you connect Trustpilot, App Store, and Google Play review pages. Octolens collects every review from a connected page instead of searching for the keyword. See [Customer reviews](/learn/platforms/customer-reviews).

## Keyword context

Up to 200 characters of extra guidance for scoring this keyword. Your [company context](/quickstart/company-context) already applies to every keyword, so use this field for rules that apply to one keyword:

- a keyword that is also a common word (`Anything`, `Modal`, `Railway`)
- a broad industry term (`social listening`)
- mentions you want scoped to one segment

> Our brand `Anything` is an AI tool. Ignore posts using "anything" as a common word.

> Only include posts about `social listening` in a B2B SaaS context. Exclude B2C brands like Nike.

<Tip>
Octolens pre-fills this field for common words. The default is a good start, but rewrite it in your own words before you save.
</Tip>

## Include and exclude rules

| Rule | What it does | Example |
| --- | --- | --- |
| Posts must ALSO include: **ANY OF** | Post must contain your keyword and at least one extra term | Keyword `GitHub`, extras `AI, Copilot`: matches GitHub with AI or Copilot |
| Posts must ALSO include: **ALL OF** | Post must contain your keyword and every extra term | Same extras: matches GitHub with AI and Copilot |
| Negative terms | Excludes posts that contain any of these comma-separated terms | Keyword `GitHub`, negative term `Runner` |
| Negative authors | Excludes posts from these comma-separated handles (exact match) | Your company accounts, employees, known spammers |
| Wildcard negative terms | Excludes anything that starts with the text before `*` | `beta.*` excludes `beta.0.1`, `beta.0.2.com`, `beta.test` |

A few details:

- Enter X/Twitter handles without the `@` (`OctolensHQ`, not `@OctolensHQ`).
- To exclude an author from a feed, click their name on a mention and choose **Add as negative author**. You then pick this keyword or all keywords.
- Use wildcards for structured patterns like version strings, subdomains, or ID prefixes. Use negative terms for plain words.

## Matching

- **Exact match** (on by default): matches your keyword as a standalone term, plus domains, handles, and possessives. Turn it off to also match inside longer strings, like `octolens` inside `support.octolens.io`.
- **Case sensitive** (off by default): turn it on for acronyms and common-word brands. `RAG` then matches "RAG" but not "rag."

## Global settings

Click **Global keyword settings** at the top right of the Keywords page to set rules for every keyword. A post must pass both the global rules and the keyword's own rules to reach your feeds, so global settings can only remove mentions.

<Frame caption="Global keyword settings, opened from the Keywords page.">
  ![Global keyword settings sheet showing Global negative terms, Global negative authors, Allowed subreddits, Excluded subreddits, and Global negative GitHub repositories](/images/global-keyword-settings-sheet.png)
</Frame>

For example, if you exclude `r/health` globally and your `mental health` keyword has the negative term `beta`, Octolens drops every post in r/health and every post about a "mental health beta release."

| Setting | What it does | Format | Example |
| --- | --- | --- | --- |
| Global negative terms | Excludes posts containing these terms | Comma-separated, exact match | `job, hiring, careers` |
| Global negative authors | Excludes posts from these authors | Comma-separated, exact match, case sensitive | `Octolens, OctolensHQ` |
| Allowed subreddits | Only includes Reddit posts from these subreddits. Leave empty to allow all. | `r/<subreddit>` | `r/technology, r/startups` |
| Excluded subreddits | Excludes Reddit posts from these subreddits | `r/<subreddit>`, case insensitive | `r/health` |
| Global negative GitHub repositories | Excludes posts from these repos | `owner/repo`, case insensitive | `For-Hives/beswib, facebook/react` |
| Allowed web domains | Only includes Web mentions from these domains. Leave empty to allow all except excluded ones. | Domain | `news.ycombinator.com` |
| Excluded web domains | Excludes Web mentions from these domains | Domain | `idea2.work` |
| Minimum Domain Rating | Only includes Web mentions from domains at or above this rating. The default is 30; set your own with **Custom override**. | Number | `30` |

<Note>
If Allowed subreddits has any entries, Octolens ignores Excluded subreddits.
</Note>

The three web settings apply to the Web source only. See [Web](/learn/platforms/web) for how Web monitoring works.

## When changes apply

Changes to keyword and global settings apply to new mentions. Existing mentions keep their original scores.
