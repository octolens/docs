---
title: "Claude Desktop & Web"
description: "Connect Octolens to Claude Desktop or claude.ai and ask about your mentions in plain language."
---

You connect Claude with a server URL and sign in with your Octolens account. There's no API key to paste.

<Tip>
You can also start this from the app: **Settings → MCP → Setup Octolens MCP** walks you through the same steps.
</Tip>

## Option 1: Connectors (Pro, Max, Team and Enterprise)

<Steps>
  <Step title="Add a custom connector">
    In Claude, go to **Settings → Connectors → Add Custom Connector** and paste this URL:

    ```text
    https://app.octolens.com/api/mcp/v2
    ```
  </Step>
  <Step title="Sign in to Octolens">
    Claude opens a browser tab. Sign in with your Octolens account and approve the connection. You don't need a client ID or secret.
  </Step>
</Steps>

## Option 2: Config file (mcp-remote)

<Steps>
  <Step title="Edit your config file">
    - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
    - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`

    ```json
    {
      "mcpServers": {
        "octolens": {
          "command": "npx",
          "args": [
            "mcp-remote",
            "https://app.octolens.com/api/mcp/v2"
          ]
        }
      }
    }
    ```
  </Step>
  <Step title="Restart Claude Desktop">
    Restart the app after saving. On first use, a browser tab opens so you can sign in to Octolens.
  </Step>
</Steps>
