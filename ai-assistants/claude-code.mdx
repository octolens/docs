---
title: "Claude Code"
description: "Connect Octolens to Claude Code and work with your mentions from the terminal."
---

You add Octolens with one command and sign in with your Octolens account. There's no API key to paste.

<Tip>
You can also start this from the app: **Settings → MCP → Setup Octolens MCP** walks you through the same steps.
</Tip>

<Steps>
  <Step title="Add the server">
    ```bash
    claude mcp add --transport http octolens \
      "https://app.octolens.com/api/mcp/v2"
    ```

    The server now shows as `needs authentication`. The next step signs you in.
  </Step>
  <Step title="Sign in">
    Run `/mcp` inside Claude Code and pick **octolens → Authenticate**. A browser tab opens. Sign in to Octolens and approve the connection. The server then shows as connected:

    ```text
    /mcp
    ⎿ MCP Server Status
      • octolens: connected
    ```
  </Step>
</Steps>

Add `--scope user` to use Octolens in every project, or `--scope project` to share it with your team through `.mcp.json`.
